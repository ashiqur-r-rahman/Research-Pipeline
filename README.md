## 📝 Step-by-Step Guide

### 1. Clarify the Research Question *(1–3 days)*
- Define a clear, focused, answerable question.
- Check if it’s original and important.
- **Tools**: 
  <details>
  <summary>🔍 Click to view recommended tools</summary>
  <br>
  • <a href="https://scholar.google.com/" target="_blank"><strong>Google Scholar</strong></a>: Free search engine for scholarly literature across disciplines.<br>
  • <a href="https://www.semanticscholar.org/" target="_blank"><strong>Semantic Scholar</strong></a>: AI-powered search with smart filters and strong citation graphs.<br>
  • <a href="https://consensus.app/" target="_blank"><strong>Consensus</strong></a>: AI search synthesizing evidence-based answers from 200M+ papers.<br>
  • <a href="https://elicit.com/" target="_blank"><strong>Elicit</strong></a>: AI assistant for extracting key findings into structured tables.
  </details>

### 2. Broad Literature Discovery *(3–7 days)*
- Cast a wide net to understand the field.
- **Tools**:
  <details>
  <summary>🕸️ Click to view recommended tools</summary>
  <br>
  • <a href="https://www.researchrabbit.ai/" target="_blank"><strong>ResearchRabbit</strong></a>: "Spotify for papers" building visual citation maps from seed papers.<br>
  • <a href="https://www.connectedpapers.com/" target="_blank"><strong>Connected Papers</strong></a>: Visual tool generating interactive graphs of related papers via citation networks.<br>
  • <a href="https://elicit.com/" target="_blank"><strong>Elicit</strong></a>: Deep, multi-step search for hard-to-find papers.
  </details>

### 3. Deep Literature Review & Synthesis *(1–3 weeks)*
- Read, extract, and organize key findings.
- Organize everything in a reference manager.
- **Tools**:
  <details>
  <summary>📂 Click to view recommended tools</summary>
  <br>
  • <a href="https://www.zotero.org/" target="_blank"><strong>Zotero</strong></a>: Free open-source reference manager (highly recommended).<br>
  • <a href="https://scispace.com/" target="_blank"><strong>SciSpace</strong></a>: Chat with PDFs, summarize, and extract data.<br>
  • <a href="https://scite.ai/" target="_blank"><strong>Scite</strong></a>: Check whether papers are supported or contradicted by later work.<br>
  • <a href="https://consensus.app/" target="_blank"><strong>Consensus</strong></a>: Map where evidence agrees or disagrees.
  </details>

### 4. Identify the Gap & Refine Contribution
- After synthesizing, clearly state:
  1. What is known.
  2. What is missing or weakly studied.
  3. Exactly what your paper will add.
- *Action*: Write a short 1-page research gap memo.

### 5. Design Methods / Experimental Plan
- Choose appropriate methods, data sources, sample, and analysis plan.
- Pre-register if needed (especially for experimental work).
- Get ethical approval if required.

### 6. Collect / Generate Data
- Run experiments, surveys, simulations, or secondary data analysis.
- Keep raw data + analysis scripts organized from day one.
- **Resources**:
  <details>
  <summary>🧬 Click to view recommended resources</summary>
  <br>
  • <a href="https://www.ncbi.nlm.nih.gov/" target="_blank"><strong>NCBI</strong></a>: Free access to biomedical/genomic info (PubMed, GenBank) for life sciences research.
  </details>

### 7. Analyze Data
- Clean, analyze, and visualize.
- Use proper statistical / computational methods.
- Document every decision in your code or lab notebook.

### 8. Write the First Full Draft
> **Recommended writing order**: Methods → Results → Discussion → Introduction → Abstract & Title (last).
- **Writing Helpers**:
  <details>
  <summary>✍️ Click to view recommended tools</summary>
  <br>
  • <a href="https://scispace.com/" target="_blank"><strong>SciSpace AI Writer</strong></a>: For drafting and polishing academic language.<br>
  • <a href="https://www.zotero.org/" target="_blank"><strong>Zotero</strong></a>: For citations (never type references manually).
  </details>

### 9. Self-Review & Strengthening
- Check logic, flow, and whether claims are supported by evidence.
- Use <a href="https://scite.ai/" target="_blank"><strong>Scite</strong></a> again to ensure key citations are solid.
- Ask yourself: *"Would a critical reviewer accept this?"*

### 10. Get Feedback
- Share with supervisor, colleagues, or a writing group.
- Revise based on feedback (this step usually provides the biggest quality jump).

### 11. Final Polish
- Proofread carefully (use tools + human check).
- Format strictly according to target journal guidelines.
- Prepare cover letter, highlights, and graphical abstract (if needed).

### 12. Submit → Peer Review → Revise → Accept
- Choose the right journal (match scope + impact factor).
- Respond to reviewers thoroughly and politely.
- After acceptance: proof → publish.
- **Publishers**:
  <details>
  <summary>🏢 Click to view publisher info</summary>
  <br>
  • <a href="https://www.elsevier.com/" target="_blank"><strong>Elsevier</strong></a>: Major global publisher (ScienceDirect, Scopus, The Lancet, Cell).
  </details>
